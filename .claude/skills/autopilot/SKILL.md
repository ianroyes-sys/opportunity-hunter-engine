# Manual autopilot
Read CLAUDE.md, autopilot/UNATTENDED.md and autopilot/CONFIG.md. The active engine policy applies equally to manual and scheduled work.
Use scripts/run_lane.sh opportunity for a scheduled-style Apply run; it checks STOP/pause and refreshes the queue first. Do not start another browser worker alongside an active run.
For direct manual operation, prepare the compact engine packet, follow the current Apply spec, and finish actionable applications with evidence. Never reopen legacy awaiting-ian rows or skipped candidates merely because their old status looks ready.
If new discovery is required by the user's request, follow the current Hunt spec using public search only; add verified structured candidates, refresh the packet and continue Apply. No fixed batch floor or invented completion quota.
Known-profile answers and permitted grounded essays are autonomous. One unavailable required personal fact/action defers that candidate without a question. No faculty/transcript chase, fee, sensitive identifier, CAPTCHA bypass or false attestation.
Update the engine outcome, human-readable receipt and dashboard. Report actual submissions and remaining work when manually asked; no unsolicited email digest.
